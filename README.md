# Telegram-бот для приёма заявок (демо)

Прототип бота на Python (aiogram 3) в Docker: квалификация клиента, карточка заявки менеджеру, пересылка макетов без сжатия.

## Возможности
- Диалог по системному промту и базе знаний из `knowledge/` (меняются без пересборки)
- Память диалога (последние 20 сообщений)
- Карточка заявки с отправкой в чат менеджеров (команда `/demo` показывает формат)
- Приём файлов (CDR, DXF, PDF и др.) и пересылка менеджеру в исходном виде
- Вызов модели (Claude или ChatGPT) подключается ключом в `.env`

## Запуск
1. `cp .env.example .env` и заполнить `BOT_TOKEN`, `MANAGER_CHAT_ID`, `LLM_API_KEY`
2. `docker compose up -d --build`

Это демо-прототип, не коммерческий проект.
