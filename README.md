# Telegram-бот для приёма заявок

Бот на Python (aiogram 3) в Docker. Консультирует клиентов по базе знаний, выясняет параметры заказа и контакты, принимает файлы-макеты и пересылает их менеджеру без сжатия. Модель (Claude или ChatGPT) подключается вашим API-ключом.

## Что понадобится
- Сервер с Docker и Docker Compose (достаточно VPS на 1 ГБ памяти)
- Токен бота от @BotFather
- Ключ API модели (Anthropic или OpenAI)
- Telegram ID чата менеджеров (для группы число отрицательное; бот должен быть в группе)

## Установка
1. Скопируйте проект на сервер и перейдите в его папку.
2. Создайте файл настроек: `cp .env.example .env`
3. Заполните в `.env`:
   - `BOT_TOKEN` токен бота
   - `MANAGER_CHAT_ID` ID чата менеджеров
   - `LLM_API_KEY` ключ API
   - `LLM_PROVIDER` = `anthropic` или `openai`
   - `LLM_MODEL` название модели (для OpenAI обязательно, для Anthropic можно оставить пустым)
   - `TIMEZONE` например `Europe/Moscow`
4. Запустите: `docker compose up -d --build`

## Как менять тексты без программиста
Файлы в папке `knowledge/`:
- `system_prompt.md` поведение бота: тон, вопросы, правила
- `price.md` база знаний: материалы, сроки, услуги, цены

Измените текст и сохраните. Бот читает файлы при каждом сообщении, перезапуск не нужен.

## Команды
- `docker compose up -d` запустить
- `docker compose down` остановить
- `docker compose logs -f` смотреть логи
- `docker compose up -d --build` применить обновление кода

## Команды бота
- `/start` начать диалог заново
- `/demo` отправить тестовую карточку заявки в чат менеджеров
- `/id` показать ID текущего чата (удобно для настройки `MANAGER_CHAT_ID`)

## Безопасность
- Файл `.env` содержит секреты: не публикуйте его и не отправляйте в мессенджеры.
- Если токен или ключ попали в чужие руки, перевыпустите: `/revoke` в @BotFather, новый ключ в кабинете провайдера.

## Ограничения демо-версии
- История диалога хранится в памяти и сбрасывается при перезапуске бота.
- Карточка заявки показывается командой `/demo`; автоматическое заполнение из диалога настраивается под ваш скрипт.
- Прямая интеграция с CRM не входит в базовую версию.
